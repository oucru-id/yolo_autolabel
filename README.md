# YOLO Bukukia Training Pipeline

An end-to-end YOLO object detection pipeline for the Bukukia Segmentation project.

**Features:** Focal Loss support, IoU callback tracking, DPI-aware preprocessing, coordinate-descent hyperparameter tuning, comprehensive evaluation with per-class metrics.

> Dokumentasi lengkap (Bahasa Indonesia, ditulis per role): [`docs/INDEX.md`](docs/INDEX.md).

## Pipeline Overview

```
Phase 1: Training (train_2.py)
  raw_images/ + labels/ → dataset split → YOLO training (Focal Loss + IoU callback)
  → results/runs/train/weights/best.pt

Phase 2: Evaluation (test_model.py)
  best.pt + test-dataset/ → dashboard, annotated images, metrics CSV
  → results/test_results/

Phase 3: Fine-Tuning — optional (fine_tune.py)
  best.pt + data.yaml → hyperparameter search
  → results/runs/fine_tune/
```

## Quick Start

### Prerequisites

```bash
pip install -r requirements.txt
```

### Phase 1: Training

1. Place training images in `input_files/raw_images/`
2. Place YOLO labels in `input_files/export/labels/`
3. Place class names in `input_files/export/classes.txt` (one per line)
4. Run:

```bash
python scripts/train_2.py \
    --model yolo26n.pt \
    --epochs 50 \
    --imgsz 640 \
    --batch -1 \
    --fl-gamma 1.5 \
    --fl-alpha 0.25
```

**Training arguments:**

| Argument | Type | Default | Description |
|---|---|---|---|
| `--model` | str | config | Model name or path |
| `--epochs` | int | config | Training epochs |
| `--imgsz` | int | `640` | Image size |
| `--batch` | int | `-1` | Batch size (`-1` = auto) |
| `--limit` | int | `0` | Limit total images (0 = all) |
| `--fraction` | float | `0.0` | Use % of data (overrides `--limit`) |
| `--images-dir` | str | `raw_images` | Custom image folder |
| `--split-dir` | str | — | Pre-split dataset (skips auto-split) |
| `--fl-gamma` | float | `1.5` | Focal Loss gamma (0.0 = disable) |
| `--fl-alpha` | float | `0.25` | Focal Loss alpha |

### Phase 2: Model Evaluation

```bash
python scripts/test_model.py \
    --conf 0.25 \
    --model results/runs/train/weights/best.pt \
    --data input_files/test-dataset
```

### Phase 3: Fine-Tuning (Optional)

```bash
python scripts/fine_tune.py \
    --model results/runs/train/weights/best.pt \
    --iterations 30 \
    --epochs 30
```

## Running on Google Colab

1. Upload this folder to **Google Drive** (exclude `.venv/` and `results/runs/`).
2. Open the appropriate notebook (v2.3 for standard, v3.x for DPI-aware) in Colab.
3. Enable GPU: **Runtime → Change runtime type → T4 GPU**.
4. Update `project_path` to match your Google Drive folder name.
5. Run cells sequentially.

The pipeline auto-detects Colab and adjusts paths to `/content/drive/MyDrive/<your_folder>`.

---

## Running on GCP VM

1. Clone or upload the project to the VM.
2. Open the `*_vm.ipynb` notebook in JupyterLab or VS Code.
3. Update `PROJECT_DIR` to your actual project path.
4. Run cells sequentially — GPU is accessed directly via CUDA.

## Configuration Reference

All settings are in `scripts/config.py` and can be overridden via environment variables:

| Variable | Default | Description |
|---|---|---|
| `YOLO_MODEL` | `yolo26n.pt` | Base model name |
| `YOLO_EPOCHS` | `50` | Training epochs |
| `YOLO_IMGSZ` | `640` | Image size |
| `YOLO_CONF` | `0.25` | Detection confidence threshold |
| `YOLO_OPTIMIZER` | `AdamW` | Optimizer (`AdamW`, `SGD`, `Adam`) |
| `YOLO_LR0` | `0.001` | Initial learning rate |
| `YOLO_LRF` | `0.01` | Final learning rate ratio |
| `YOLO_COS_LR` | `True` | Cosine LR schedule |
| `YOLO_PATIENCE` | `20` | Early stopping patience (epochs) |
| `YOLO_RESUME` | `False` | Auto-resume interrupted training |

DPI-specific settings (for v3 notebooks):

| Variable | Default | Description |
|---|---|---|
| `ORIGINAL_DPI` | `600` | Production image resolution |
| `TRAINING_DPI` | `96` | Training image resolution |

## Scripts Reference

### Core Pipeline

| Script | Purpose |
|---|---|
| `config.py` | Centralized configuration (paths, model, hyperparameters) |
| `train_2.py` | Training with Focal Loss and IoU callback |
| `test_model.py` | Model evaluation with dashboard, annotated images, per-image metrics |
| `fine_tune.py` | Ultralytics `model.tune()` hyperparameter search |
| `fine_tune_tuningmanual.py` | Manual coordinate-descent hyperparameter sweep |
| `analyze.py` | Post-training analysis (plateau detection, diagnostics, dashboard) |
| `iou_callback.py` | IoU tracker callback for training |

### Evaluation Tools

| Script | Purpose |
|---|---|
| `evaluate_iou_full.py` | Full IoU evaluation on validation set |
| `evaluate_iou_full_train.py` | Full IoU evaluation on training set |
| `evaluate_iou_train.py` | Simplified IoU evaluation on training set |
| `predict_to_labels.py` | Export YOLO predictions as label .txt files |
| `extract_label_details.py` | Extract label annotations to CSV |

### Data Management (Colab Utilities)

| Script | Purpose |
|---|---|
| `copy_images_from_labels_colab.py` | Copy images matching label filenames |
| `filter_images_colab.py` | Copy images matching CSV filenames |
| `filter_labels_colab.py` | Copy labels matching CSV filenames |
| `filter_labels_by_segment_colab.py` | Filter labels by class IDs (e.g. 2023/2024 segments) |
| `move_random_images_colab.py` | Randomly move/copy N images (with labels) |

### Other

| Script | Purpose |
|---|---|
| `generate_report.py` | Generate Markdown summary report |
| `run_pipeline.py` | Full pipeline orchestration with HTML report |
